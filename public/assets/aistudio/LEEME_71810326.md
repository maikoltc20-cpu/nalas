# Nala · Propuesta visual 01

Abrí **abrir-prototipo.html** en un navegador. No necesita instalar nada ni conectarse a internet. El menú recorre siete pantallas: Nala, Mi asistente, Prueba, Atención, Gestión, Mi negocio y Administración. Prueba se abre desde Mi asistente.

Es una referencia de diseño con acciones ilustrativas, no una conexión a tu aplicación ni un cambio publicado. Los datos son ejemplos visuales. El prototipo usa la misma paleta en todas las vistas. La marca tipográfica es provisional.

Para Google AI Studio: adjuntar este ZIP y pedir “Leé ENCARGO_GOOGLE_IA.md y aplicá primero la entrega visual sobre el código actual. Usá abrir-prototipo.html como referencia. Conservá el acceso actual y las funciones operativas. No actives servicios ni agregues dependencias”.

El encargo incluye el comportamiento de potencial ya acordado, pero propone completar solo lo que falte en una segunda entrega acotada. El tablero de Gestión es referencia; no exige desarrollar arrastre de tarjetas.

Colores: fondo gris suave, superficies blancas, acciones verde petróleo, estados menta, pendientes durazno y manual lavanda. Se busca claridad y calidez sin copiar una marca comercial.

Nota: no se incluyen capturas renderizadas de las siete vistas porque el entorno impidió ejecutar el navegador de renderizado. El archivo HTML contiene los diseños completos; revisarlos visualmente antes de implementar. El esquema PNG adjunto es un resumen visual, no una captura del prototipo.
